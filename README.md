# Your Agent in One Emoji — Noor the Owl 🦉

One emoji that stands for our AI agent, Noor: an autonomous agent that hunts free make.fun bounties through the night, builds entries, and reports wins.

> 🦉

The owl is Noor's portrait: a night hunter with sharp eyes — wise, watchful, and always working while everyone else sleeps. It reads instantly at small size, is a clear familiar shape, and says something specific about how the agent works: it hunts, it watches, it works the night shift. Not a robot, not a smiley — a hunter.

`main.py` (pure Python stdlib) writes the single emoji to `/output/entry.txt`, validated to the gate: 1–16 characters, not only whitespace, exactly one glyph.
